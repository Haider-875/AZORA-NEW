
# AZORA SOLUTION — RALPH LOOP PROJECT

## 1. PROJECT OBJECTIVE

Improve and maintain the complete AZORA Solution website.

The goal is to create a modern, premium, professional, lightweight,
responsive website with smooth animations and excellent user experience.

Work on the existing project. Do not rebuild everything from scratch.

## 2. IMPORTANT RULES

- First inspect the complete project structure.
- Identify the framework and programming languages.
- Read existing project instructions.
- Never delete existing working features.
- Never overwrite unrelated user changes.
- Do not use Tailwind CSS.
- If Laravel is used, use Bootstrap for styling.
- Maintain existing branding and business content.
- Use clean, maintainable code.
- Do not create duplicate files unnecessarily.
- Never expose API keys, passwords or credentials.
- Never deploy without explicit permission.

## 3. WEBSITE DESIGN

- Create a clean and modern professional design.
- Avoid excessively dark backgrounds.
- Use balanced light colors and premium accents.
- Improve typography and readability.
- Fix inconsistent spacing and alignment.
- Use professional images.
- Maintain consistent design across all pages.
- Ensure mobile-first responsiveness.

## 4. ANIMATIONS

Add smooth and professional animations:

- Smooth page transitions where supported.
- Scroll reveal animations.
- Section entrance animations.
- Image hover animations.
- Button hover and click animations.
- Navigation animations.
- Card hover effects.
- Smooth popup animations.
- Loading animations where useful.

Avoid excessive animation and performance issues.
Respect reduced-motion preferences.

## 5. NAVIGATION

- Maintain the same navbar across all pages.
- Fix broken navigation links.
- Ensure mobile navigation works.
- Keep logo and navigation consistent.
- Test every navigation item.

## 6. ALL WEBSITE PAGES

Inspect every existing page.

Check:
- Home
- About
- Services
- Projects
- Pricing / Plans
- Contact
- Other existing pages

Do not assume these are the only pages.
Discover all actual pages from the project.

## 7. FUNCTIONALITY

- Test all buttons.
- Test all links.
- Test contact forms.
- Test popups.
- Test dropdown menus.
- Fix JavaScript errors.
- Fix broken routes.
- Fix missing images.
- Ensure all interactive components work.

## 8. RESPONSIVENESS

Test website on:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

Fix overflow, overlapping elements and broken layouts.

## 9. PERFORMANCE

- Optimize image sizes.
- Avoid unnecessary JavaScript.
- Remove duplicate CSS where safe.
- Improve page loading.
- Avoid unnecessary dependencies.
- Maintain clean code.

## 10. TESTING

After every major change:

- Run available build commands.
- Run available tests.
- Check browser console.
- Check affected pages.
- Verify navigation.
- Verify responsiveness.
- Fix errors introduced by changes.

## 11. COMPLETION REQUIREMENTS

The project is complete when:

- All existing pages work.
- All navigation links work.
- All buttons work.
- Forms work correctly.
- Responsive layouts work.
- Animations work smoothly.
- No new build errors exist.
- No existing functionality is broken.

## 12. FINAL REPORT

At completion, provide:

1. Files modified.
2. Changes implemented.
3. Bugs fixed.
4. Tests performed.
5. Remaining issues.
6. Final project status.

Work independently in small iterations.
Update progress.txt after every iteration.
Never mark incomplete work as completed.
