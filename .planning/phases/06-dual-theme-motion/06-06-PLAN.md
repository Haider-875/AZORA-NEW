# Plan 6.6: Responsive Design & Cross-Device Breakpoint Audit

## Objective
Verify and optimize layout, readability, tap targets, and visual balance across every standard device viewport in both Light and Dark themes.

## Viewport Standards to Verify:
1. `390px` — Compact Mobile (iPhone 12/13/14/15)
2. `576px` — Large Mobile / Phablet
3. `768px` — Tablet Portrait (iPad Mini / Standard)
4. `1024px` — Tablet Landscape / Small Laptop
5. `1440px` — Desktop Standard
6. `1920px` — Ultra-Wide Desktop

## Tasks
1. Audit and resolve any horizontal overflows (`scrollWidth > clientWidth`).
2. Verify touch targets (`min-height: 44px`) on mobile navigation, filter pills, and form checkboxes.
3. Verify mobile drawer navigation toggle, typography scale, and phone CTA links.
4. Verify dual-theme appearance across all viewports.
5. Verify 56/56 automated tests pass.
