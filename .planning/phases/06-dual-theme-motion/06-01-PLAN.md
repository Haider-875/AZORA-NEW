# Plan 6.1: Dual Theme Architecture, Design Tokens & FOUC-Free Persistence

## Objective
Establish a clean CSS custom property architecture supporting both the Light Theme (Signature Azora Blue `#CCE8FF`) and the Dark Theme (Preserved Azora Cyber Glass identity), with zero flash-of-unstyled-theme on page load.

## Design Tokens

### Light Theme (`[data-bs-theme="light"]`)
- `--az-bg-base`: `#CCE8FF` (Signature soft sky blue)
- `--az-bg-surface`: `#FFFFFF` (Crisp white elevated cards)
- `--az-bg-surface-secondary`: `#F4F9FF` (Soft tinted surface for nested cards & inputs)
- `--az-text-main`: `#10243A` (Deep navy high-contrast text)
- `--az-text-muted`: `#52677D` (Balanced slate text)
- `--az-primary`: `#1769E8` (Cobalt agency primary CTA / accent)
- `--az-secondary-accent`: `#6B8DFF` (Periwinkle gradient/glow accent)
- `--az-border`: `#D5E6F5` (Subtle blue-tinted borders)
- `--az-glass`: `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(16px)`

### Dark Theme (`[data-bs-theme="dark"]`)
- `--az-bg-base`: `#040810`
- `--az-bg-surface`: `#08101E`
- `--az-bg-surface-secondary`: `#0B1320`
- `--az-text-main`: `#F8FAFC`
- `--az-text-muted`: `#94A3B8`
- `--az-primary`: `#001D64` / `#2469EB`
- `--az-cyan`: `#38BDF8`
- `--az-border`: `rgba(255, 255, 255, 0.08)`
- `--az-glass`: `rgba(7, 11, 20, 0.82)` with `backdrop-filter: blur(24px)`

## Tasks
1. Define comprehensive CSS token variables in `public/assets/css/azora-modern.css` under `:root`, `[data-bs-theme="light"]`, and `[data-bs-theme="dark"]`.
2. Implement inline theme preloader in `<head>` of `resources/views/layouts/app.blade.php` to immediately read `localStorage.getItem('azora_theme')` with `matchMedia('(prefers-color-scheme: dark)')` fallback, preventing FOUC.
3. Establish global smooth color transition token (`--az-theme-transition: background-color 0.3s ease, color 0.3s ease, border-color 0.3s ease`).
4. Verify all 56 tests pass.
