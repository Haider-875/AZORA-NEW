# Plan 6.2: Global Navigation, Theme Switcher & Core Components

## Objective
Implement an accessible, smooth Sun/Moon theme switcher in the global header, and redesign shared components (navbar, footer, buttons, dropdowns, modals, and floating action trigger) to seamlessly adapt between Light and Dark themes.

## Tasks
1. Add interactive Sun/Moon theme toggle button to `resources/views/components/navbar.blade.php` (both desktop bar and mobile drawer).
2. Wire up `AZ.toggleTheme()` in `public/assets/js/app.js` with `localStorage` persistence and smooth icon rotation.
3. Redesign `resources/views/components/navbar.blade.php`:
   - Light mode: crisp frosted white glass (`rgba(255, 255, 255, 0.85)`), deep navy text, brand icon blue glow.
   - Dark mode: deep obsidian glass (`rgba(7, 11, 20, 0.85)`), white text, cyan icon glow.
4. Redesign `resources/views/components/footer.blade.php`:
   - Dual-theme background (soft cobalt radial in light mode; deep void radial in dark mode).
   - Dynamic watermark styling fading smoothly in both themes.
5. Calibrate shared components: primary & secondary buttons, modal backdrop & container, form inputs, dropdown menus.
6. Verify 56/56 automated tests pass.
