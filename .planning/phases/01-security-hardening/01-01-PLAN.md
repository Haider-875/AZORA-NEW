# Plan 1.1: Native Admin Authentication & Dashboard Route Lockdown

## Tasks
1. Configure guest redirection to `/dashboard/login` and user redirection to `/dashboard` in `bootstrap/app.php`.
2. Seed default admin user (`admin@azorasolution.com`) in `database/seeders/DatabaseSeeder.php` using bcrypt hashing (`Hash::make(...)`).
3. Refactor `app/Http/Controllers/DashboardController.php`:
   - `login()`: Redirect to `dashboard.index` if `Auth::check()`.
   - `authenticate()`: Use `Auth::attempt()`, call `$request->session()->regenerate()`.
   - `logout()`: Use `Auth::logout()`, `$request->session()->invalidate()`, and `$request->session()->regenerateToken()`.
   - `updatePassword()`: Validate current password with `Hash::check()`, update authenticated user password with `Hash::make()`.
4. Wrap administrative routes in `routes/web.php` inside `Route::middleware(['auth'])->group(...)`:
   - `/dashboard`
   - `/dashboard/lead/{id}/read`
   - `/dashboard/lead/{id}`
   - `/dashboard/export`
   - `/dashboard/password`
5. Create and run `tests/Feature/AdminAuthSecurityTest.php` to verify all security boundaries.
